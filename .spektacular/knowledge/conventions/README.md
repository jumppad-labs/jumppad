# Conventions

**Tier:** always-applied

**Purpose:** The rules a team always wants honoured — coding standards, naming schemes, formatting, required patterns, and the house style that every change must follow.

**Belongs elsewhere:** Not the reasoning behind a rule (that is a decision) and not a one-off lesson learned in passing (that is a learning). A convention is a standing rule, stated as an instruction to follow.

**Entry shape:** An imperative rule with, where useful, a brief note on its scope — short enough to apply without re-reading.
