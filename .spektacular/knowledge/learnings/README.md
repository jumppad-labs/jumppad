# Learnings

**Tier:** looked-up

**Purpose:** Empirical knowledge gained from doing the work — what was tried, what worked, what did not, and the practical findings that save the next contributor from repeating the effort.

**Belongs elsewhere:** Not a recorded decision with its rationale (that is a decision) and not a standing rule the team must follow (that is a convention). A learning is an observation from experience.

**Entry shape:** A finding stated plainly, with enough context to know when it applies.
