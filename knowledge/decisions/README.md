# Decisions

**Tier:** looked-up

**Purpose:** The reasoning behind choices the project has made — the options considered, the trade-offs weighed, and why one path was taken over the others (ADR-style).

**Belongs elsewhere:** Not a description of the resulting structure (that is architecture) and not a rule to follow (that is a convention). A decision records the why, not the what or the how.

**Entry shape:** A record of the decision, the alternatives considered, and the rationale for the choice made.
